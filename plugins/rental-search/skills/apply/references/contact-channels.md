# Contact channels

Sites change their pages often. Treat this as a starting point: always look at the page in front of you, and update this file when something differs.

| What you see | What to do |
|---|---|
| A contact form on the listing page (name, email, phone, message) | Read its fields now; fill it from My application only after the ok (`SKILL.md` step 5). Most agency listings on SeLoger and Bien'ici work this way. |
| A « Contacter » button that opens a messaging thread inside the site | Usually needs an account: ask the user to log in. Write in the thread only after the ok (`SKILL.md` step 5). Leboncoin and PAP generally work this way. |
| An agency email address in the ad | Gmail draft to that address, subject "Application — <listing title>", in the listing's language. |
| A phone number only | Give the number and a 3-line call script. Never call. |
| A link to the agency's own site | Open it; if the same listing has a form there, use it. If not, fall back to the portal's channel. |
| « Déposer votre dossier » on a third-party platform | Use the DossierFacile link if the platform accepts it; otherwise ask the user, never upload documents yourself. |

## Message length

Keep the adapted message under the field's limit. If the site truncates, shorten the middle sentences, never the first line or the signature.

## What never goes into a form

Bank details, ID numbers, documents, passwords, or any figure the user did not put in My application.
